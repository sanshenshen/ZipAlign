# ZipAlign

[English README](./README.md)

## 项目用途

ZipAlign 是一个运行在 Android 设备上的 APK 对齐工具，用来直接在手机或平板上校验并修复 APK 对齐。

它适合这些场景：

- 检查一个 APK 是否已经正确对齐。
- 重新生成一个对齐后的 APK。
- 直接在设备存储里浏览并选择 APK，不需要先拷到电脑。
- 把处理后的 APK 直接导出到当前目录。

## 主要功能

- Android 全部文件访问后的存储浏览。
- 文件管理器式目录导航。
- 支持识别 `.apk` 和 `.apk.1` 这类 APK-like 文件。
- APK 选择与基础信息查看。
- 类似 `zipalign` 的对齐校验。
- 对齐重写并导出新 APK。
- 支持对未压缩 `.so` 文件启用页面对齐。
- 在界面中展示结果摘要和操作日志。

## 典型使用流程

1. 授予全部文件访问权限。
2. 浏览到 APK 所在目录。
3. 选择要处理的 APK。
4. 点击 `Verify` 执行对齐校验。
5. 点击 `Align and Export` 在当前目录生成对齐后的 APK。

## 当前界面特点

- 文件管理器式浏览区。
- 进入文件夹和返回文件夹都有过渡动画。
- APK 使用自定义 Android 风格图标。
- 浏览区高度稳定，进入内容较少的文件夹时不会让下方区域突然上冲。
